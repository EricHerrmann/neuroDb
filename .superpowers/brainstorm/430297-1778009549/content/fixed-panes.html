How it works in Streamlit

CSS injection via st.markdown(unsafe_allow_html=True) sets each column to height: calc(100vh - Npx) with overflow-y: hidden on the outer container. The transcript container gets overflow-y: auto; flex: 1. The input stays at the bottom via flexbox. The same pattern applies to the right pane. No Streamlit internals change — only CSS overrides.
